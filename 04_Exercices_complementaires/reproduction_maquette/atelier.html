Cible

400 × 300 px · cliquez sur une couleur pour la copier

    Critères de réussite

    • Fidélité visuelle : en mode Superposition puis Différence, aucun écart visible (seuls de fins liserés sur les bords courbes sont tolérés).
    • Code lisible et commenté : indentation régulière, noms de classes explicites, un commentaire pour chaque choix de mise en page (positionnement, calcul d'une dimension…).
    • Contraintes : HTML et CSS uniquement, sans image (ni <img>, ni url(), ni SVG).

    Superposition : la cible est affichée en transparence par-dessus votre rendu ; réglez son opacité avec le curseur.

    Différence : là où votre rendu est identique à la cible, l'image devient noire. Tout ce qui reste coloré est un écart à corriger.

    Rideau : survolez le rendu pour faire glisser la cible de gauche à droite.

    Le code est rendu tel quel dans une page vide : le body garde sa marge par défaut de 8 px (pensez à body { margin: 0 }). Il est sauvegardé dans ce navigateur, cible par cible. JavaScript est désactivé dans le rendu.
